- [Governed agentic GTM](architecture/governed-agentic-gtm.md): the full layer model and safe execution sequence
- [n8n and MCP control plane](architecture/n8n-mcp-control-plane.md): typed tool surfaces, orchestration, validation, and permissions
- [Memory, evidence, and feedback](architecture/memory-evidence-feedback.md): separate operational truth, reprocessable evidence, and outcomes

- [Knowledge promotion loop](architecture/knowledge-promotion-loop.md): session evidence, topic knowledge, authority, and promotion
- [Evidence graph](architecture/evidence-graph.md): deterministic graph construction and bounded reasoning packets
- [Portable agent runtime](architecture/portable-agent-runtime.md): role separation, routing contracts, and local runtime boundaries
- [Bounded maintenance loop](architecture/bounded-maintenance-loop.md): contract-first autonomous repair with green-or-revert behavior
- [Publication factory](architecture/publication-factory.md): reconstructive public releases with machine-enforced privacy gates
- [Polly feedback loop](architecture/polly-feedback-loop.md): idempotent human labeling, append-only feedback, and gated prompt improvement
